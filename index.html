Connect to GitHub

This admin edits the main website repository through the GitHub API. It is hosted separately, but it needs a GitHub fine-grained Personal Access Token with Contents: Read and write on the main website repo. The token stays in this browser session unless you choose to remember it on this device.

Security note

This is a static admin. The page itself can be public, but nothing can be published without a valid GitHub token. Use a fine-grained token limited to the main website repo, short expiration, and a private device. For stronger security, put this admin behind server-side authentication (Cloudflare Access/Netlify/Vercel auth/VPN).
